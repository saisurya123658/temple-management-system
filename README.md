# 🧠 Project Overview

The Temple Management System modernizes traditional temple seva booking by providing an easy-to-use digital platform for devotees and administrators.

The platform supports:

- Online seva reservations
- Temple information display
- Admin booking management
- Responsive web experience

# 🏗️ System Architecture

The project follows a modern MERN Stack architecture.

| Layer | Technology |
|------|-------------|
| Frontend | React.js + Tailwind CSS |
| Backend | Node.js + Express.js |
| Database | MongoDB |
| API Communication | Axios |
| Routing | React Router |

# ⚙️ Installation & Setup

## 📌 Requirements

Install the following software:

- Node.js
- MongoDB
- VS Code
- Git

---

# 🚀 Setup Instructions

## 1️⃣ Clone Repository

```bash
git clone https://github.com/saisurya123658/temple-management-system.git
```

---

# ⚙️ Backend Setup

## Navigate to Backend

```bash
cd backend
```

---

## Install Dependencies

```bash
npm install
```

---

## Create `.env` File

```env
MONGO_URI=your_mongodb_connection_string
PORT=6000
```

---

## Start Backend Server

```bash
node server.js
```

---

# 🌐 Frontend Setup

## Navigate to Frontend

```bash
cd frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Frontend

```bash
npm start
```

## 📋 Get All Bookings
